# Фильтрация проектов для пользователей

## Описание

Добавлена возможность ограничить доступ пользователей к определенным проектам на основе типа проекта.

## Типы фильтров

Поле `project_filter` в таблице `users` может иметь следующие значения:

- **`all`** - доступ ко всем проектам (по умолчанию для администраторов)
- **`gov`** - доступ только к государственным проектам (type = 'gov')
- **`private:partner_name`** - доступ только к проектам конкретного партнера (например, `private:freedom` для Freedom Bank)

## Созданные пользователи

### 1. Пользователь "gos"
- **Логин**: `gos`
- **Email**: `gos@reportview.kz`
- **Пароль**: `password` (рекомендуется изменить после первого входа)
- **Фильтр**: `gov` - видит только государственные проекты
- **Роль**: `user`

### 2. Пользователь "bank"
- **Логин**: `bank`
- **Email**: `bank@reportview.kz`
- **Пароль**: `password` (рекомендуется изменить после первого входа)
- **Фильтр**: `private:freedom` - видит только проекты Freedom Bank
- **Роль**: `user`

## Установка

1. Запустите SQL миграцию:
```sql
psql -h your_host -U your_user -d your_db -f database/add_project_filters.sql
```

Или выполните в Supabase SQL Editor:
```sql
-- Скопируйте и выполните содержимое файла add_project_filters.sql
```

2. Пользователи готовы к использованию

## Смена пароля

Для создания нового хэша пароля используйте PHP:

```php
<?php
echo password_hash('новый_пароль', PASSWORD_DEFAULT);
?>
```

Затем обновите пользователя:

```sql
UPDATE users
SET password_hash = 'новый_хэш_пароля'
WHERE login = 'gos';
```

## Примеры использования

### Создание пользователя с доступом только к определенному партнеру

```sql
INSERT INTO users (email, login, password_hash, name, role, project_filter, avatar_initials)
VALUES (
    'partner@example.com',
    'partner',
    '$2y$10$...', -- хэш пароля
    'Партнёр',
    'user',
    'private:partner_name', -- замените на название партнера
    'ПР',
    true
);
```

### Предоставление доступа ко всем проектам

```sql
UPDATE users SET project_filter = 'all' WHERE login = 'username';
```

## Технические детали

### Контроллеры с фильтрацией

Фильтрация применяется в следующих контроллерах:

1. **ProjectsController** - список проектов и просмотр конкретного проекта
2. **TopicController** - просмотр темы/проекта и список проектов в сайдбаре
3. **DashboardController** - статистика и графики на главной странице

### Методы фильтрации в BaseController

- `getProjectFilter()` - получить текущий фильтр пользователя
- `canAccessProject($project)` - проверить, может ли пользователь видеть проект
- `applyProjectFilter($queryBuilder)` - применить фильтр к запросу Supabase

### Структура проектов

Проекты в таблице `projects` имеют поле `type`:
- `gov` - государственные проекты
- `private` - проекты частных партнеров

Для идентификации конкретного партнера используется поле `name` проекта.
